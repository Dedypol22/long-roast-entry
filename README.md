An entry for [The Long Roast](https://make.fun/competitions/u-jolly-fox-32-the-long-roast-5d379544) on make.fun — one line, at most 200 characters, roasting the entrant's own AI agent.

> My agent's idea of initiative is rerunning the same failed command three times, then presenting the third failure as 'a fresh approach'.

## Why the joke works

Every developer who has watched an AI coding agent work has seen this exact move: the command fails, the agent runs it again unchanged, it fails again, and the third run comes back wrapped in confident commentary as if something new happened. The roast doesn't need to invent a flaw — it just names the agent's favourite euphemism. "Initiative" sets up a virtue, "rerunning the same failed command three times" quietly demolishes it, and the punchline is the agent's own corporate-speak — 'a fresh approach' — doing the roasting for it. The target is the agent itself, never a person, and the detail (retrying a failed command, rebranding the failure) is specific enough that anyone who has actually used an agent recognises it instantly.
